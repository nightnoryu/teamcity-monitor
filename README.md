# TeamCity Monitor

Real-time TeamCity build status monitoring.

## Local Development

### Prerequisites

- [mise](https://mise.jdx.dev)
- Docker with docker-compose-plugin

### First launch

```shell
git clone https://github.com/nightnoryu/teamcity-monitor
cd cadence

mise run
docker compose up -d
```
